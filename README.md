# table-component
A Bootstrap table component for Angular 15

Was initially intended to work with a proprietary component library but didn't make it in. The results of the effort are here, stripped of any proprietary information.

Features
------
* Expandable rows
* Selectable rows
* Server-side or Client-side processing
* Table state saving
* Horizontal scrolling
* Vertical scrolling
* Filtering
* Searching
* Column ordering
* Row grouping
* Full a11y compliance

Note
-----
**The demo on `ng serve` is non-functional and has degraded fidelity as it required outside data and other proprietary code. Unit tests with `ng test ui` are complete.**
